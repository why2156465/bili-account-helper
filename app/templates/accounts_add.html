IP 代理
为什么要先挂一个 IP 代理？
  • 防异地登录风控：B 站会把「突然换城市 / 换运营商登录」当成盗号，轻则弹验证码，重则限制投币、限流、禁言。给账号固定一个和你同城（或最近城市）的 IP，长期不变，最稳。
  • 避免「投不了币 / 投稿失败」：被风控标记的 IP，投币会报非法访问、投稿会失败——换回干净的同城 IP 就能恢复。
  • 多账号不串号：同一 IP 挂太多号容易被当成工作室。一个账号一个 IP，把风险摊开。
  • 全程生效：扫码 / 短信 / Cookie 导入都走这个 IP；账号添加成功后，以后所有操作也默认用它（随时可在账号卡片上改）。
